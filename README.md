# 大学生向け 年収・世帯手取りシミュレーター

大学生のアルバイト収入をもとに、本人の税・社会保険料や親の税控除が世帯の手取りに与える影響を概算するツールです。年収の壁に関する情報を整理し、働き方を考えるための参考として作成しています。

> このツールは概算です。税額・保険料・扶養の認定を確定するものではありません。実際の条件は、勤務先、加入先の健康保険、税務署などに確認してください。

## 使い方

1. `index.html` をブラウザで開きます。
2. 試算対象年に受け取った給与の合計と、給与を受け取った月数を入力します。過去年分は年間実績なら12か月を選びます。
3. 12月31日時点の年齢、試算する年分、親の所得税率の目安を入力・選択します。年末時点で20歳または60歳の場合だけ誕生月などを入力し、国民年金の対象月数を見積もります。
4. 扶養・保険・学生控除の状況を選びます。各項目の「判断の目安」を開くと、基準や参照先を確認できます。
5. 「世帯への影響を試算」を押すと、本人の税・保険、親の税控除、基準年収100万円との手取り差が表示されます。「入力をリセット」で初期状態に戻せます。

## 主な機能

- キーボードでのフォーム送信、入力項目ごとのエラー案内、入力リセット
- 受取済み給与と月数から年収を単純予測
- 本人の所得税・復興特別所得税の概算
- 勤務先の社会保険に加入した月と未加入月を分け、国民健康保険・国民年金も未加入月分を概算
- 勤労学生控除と学生納付特例を考慮した試算
- 親の所得税控除の変化と、世帯の手取り増減の概算
- 2025年分・2026年分の所得税制度を選択

## 試算の前提と制約

- 年収予測は「現在までの給与合計 ÷ 受取月数 × 12」です。今後のシフトや賞与の変化は個別に予測しません。
- 給与収入のみを前提としています。給与以外の所得や、勤労学生控除以外の所得控除は計算に含みません。
- 世帯手取りの比較基準は本人の年収100万円です。
- 住民税と親の住民税は含みません。
- 国民健康保険料は自治体や前年所得によって異なります。勤務先の社会保険料は、選択した加入月について年収を12等分した月収の約15%で概算します。未加入月の国民健康保険は簡易年額を月数按分し、国民年金は勤務先保険の加入月を除いた対象月の月額保険料を合算します。月ごとの給与額、標準報酬月額、自治体別保険料、実際の加入時期に基づく精算は再現しません。
- 扶養の認定や勤務先の社会保険への加入可否は、年収だけでは決まりません。最終的な判断は加入先の健康保険や勤務先に確認してください。
- 国民年金は年齢・誕生月から暦年内の対象月数を見積もります。20歳到達時は対象開始月、60歳到達時は対象終了月を誕生日から推定します。勤務先の加入月は選択内容を反映し、海外居住等は考慮しません。
- 学生納付特例は申請・審査が必要な納付猶予です。追納した場合の将来負担は試算に含みません。
- 2026年分の所得税改正は原則として2026年12月1日施行で、年末調整等に適用されます。制度の改正に応じて計算値の更新が必要です。

## 自動テスト

Node.js 18以降を用意し、プロジェクトフォルダーで次を実行します。追加パッケージのインストールは不要です。

```powershell
npm test
```

GitHub Actionsでも、`main`へのPR作成時とマージ後に同じテストを自動実行します。

## ファイル構成

- `index.html` — 画面、入力項目、スタイル、GitHub Pagesのトップページ
- `script_v2.js` — 入力の検証と画面表示
- `calculations.js` — 画面から独立した年収・税・保険計算
- `tests/calculations.test.js` — 年収・税・保険料の境界を含む自動テスト
- `package.json` — テスト実行コマンド
- `.github/workflows/node-tests.yml` — PR・マージ後の自動テスト
- `CHANGELOG.md` — 更新内容とフィードバックの記録
